# Try it: free sites where you practise in the browser

Learn cards ask you to **try** each new idea for 15 to 20 minutes. These free sites let you do that in a browser, with nothing to install.
A site that needs an account says so in its row.

## SQL

| Site | Address | Use it for |
|---|---|---|
| DuckDB web shell | https://shell.duckdb.org/ | Run SQL in the browser, including over a CSV or Parquet file on the internet. The Launchpad uses it. |
| SQLBolt | https://sqlbolt.com/ | Short interactive lessons on SELECT, joins and grouping. |
| PostgreSQL Exercises | https://pgexercises.com/ | Graded PostgreSQL questions, from simple SELECTs to window functions. |
| Window Functions | https://www.windowfunctions.com/ | Practice questions on window functions only. |
| DB Fiddle | https://www.db-fiddle.com/ | Create tables and run PostgreSQL queries, then share the link. |

## Python

| Site | Address | Use it for |
|---|---|---|
| Python Tutor | https://pythontutor.com/visualize.html | Run Python one line at a time and watch the variables, lists and function calls change. |
| futurecoder | https://futurecoder.io/ | A free Python course for complete beginners, with exercises and hints, in the browser. |
| Google Colab | https://colab.research.google.com/ | A notebook in the browser, with pandas and charts ready. Needs a Google account. |
| Exercism Python track | https://exercism.org/tracks/python | Short practice problems with tests. Needs a free account. |
| regex101 | https://regex101.com/ | Build and test a regular expression, with each part explained. Choose the Python flavour. |

## Git, Markdown and diagrams

| Site | Address | Use it for |
|---|---|---|
| Learn Git Branching | https://learngitbranching.js.org/ | Type real Git commands and watch commits and branches move in a picture. |
| GitHub Skills | https://skills.github.com/ | Short courses that run inside your own GitHub repository. Needs your GitHub account. |
| Markdown Live Preview | https://markdownlivepreview.com/ | Type Markdown on the left and see the result on the right. |
| Mermaid Live Editor | https://mermaid.live/ | Draw diagrams from text: flowcharts, ER diagrams and sequence diagrams. |
| dbdiagram | https://dbdiagram.io/ | Sketch tables and relationships quickly. |
| crontab guru | https://crontab.guru/ | Read and write schedule expressions such as `0 6 * * *`. |
